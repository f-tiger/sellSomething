Wix Stores: can ChatGPT actually see your products?

Direct answer: Wix automates the basics (sitemap, base Product schema, robots.txt editor) but agent-grade details need manual work: verify crawler access in SEO settings, enrich schema via code injection, and publish llms.txt through a custom route or redirect. Check where you stand with a free scan.

The Wix checklist

  1. robots.txt (SEO settings → robots.txt): confirm no Disallow for GPTBot, OAI-SearchBot, ClaudeBot, PerplexityBot, Google-Extended.
  2. Schema: Wix emits base Product markup; add GTIN and shipping/return details via SEO settings' structured-data overrides or code injection where your plan allows.
  3. llms.txt: no native support — use a URL redirect from /llms.txt to a hosted text file (keep content-type plain text). Generate the file free here.
  4. FAQ: Wix FAQ apps can emit FAQPage schema — pick one that does, and cover shipping/returns/sizing.
  5. Verify monthly: platform updates change emitted markup silently.
