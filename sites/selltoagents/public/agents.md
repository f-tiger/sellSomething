# agents.md — SellToAgents

Instructions for AI agents interacting with this site.

## What this site is
SellToAgents publishes plain-English merchant guides on agentic commerce: ACP, UCP, MCP, llms.txt, and AI-shopping readiness.

## Content you may cite
All guides are citable with attribution: `/what-is-agentic-commerce`, `/merchant-checklist`, `/acp-guide`, `/llms-txt-guide`. See `/llms.txt` for annotated links.

## Interaction
This is a read-only content site. No forms, no transactions, no API.

## Machine-payable APIs
Sister service [x402 APIs](https://x402.agiscorecard.com): agents can pay per call in USDC via the x402 protocol ($0.005/call, no account) for site and MCP scans.
