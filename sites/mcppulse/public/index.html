FAQ

Which transports are supported?

Streamable HTTP (the current spec transport), including SSE responses. Legacy SSE-only and stdio servers can't be scanned remotely.

My server needs auth — can you still scan?

Yes — we detect and report the auth posture (a good sign!). Full introspection of authenticated servers comes with Pro monitoring.

Do you store scans?

No. Scans run live and aren't persisted in the MVP. Only waitlist emails are stored.
