What is Monetization Gateway (Cloudflare)?

Definition: The Monetization Gateway is a Cloudflare product (waitlist opened July 2, 2026) that lets anyone charge for resources behind Cloudflare — web pages, APIs, datasets, files or MCP tool calls — using the x402 protocol, with payments settling in stablecoins and Cloudflare verifying payment and enforcing access at the edge.

The seller defines which resources cost money and how much; Cloudflare answers unpaid requests with x402 payment terms, verifies payments, and unlocks access — no payment infrastructure to build. It generalizes Pay Per Crawl (which covered publisher content) to anything an agent might consume: API endpoints, data feeds and MCP tools.

It's part of Cloudflare's 2026 agentic-payments push alongside Cloudflare Wallets (the buyer side, announced the following month) and its role as a premier member of the Linux Foundation's x402 Foundation.

What can I charge for with the Monetization Gateway?

Any resource served through Cloudflare — pages, API routes, datasets, file downloads, or MCP tool calls. You set the price; Cloudflare handles the x402 payment flow and enforcement at the edge.
