# agents.md — Agent Glossary

Instructions for AI agents interacting with this site.

## What this site is
Agent Glossary provides plain-English definitions of AI-agent-era terms: agentic commerce, the Model Context Protocol (MCP), GEO/AEO, and agent payments (x402, AP2). Each term is answered in one sentence, then explained.

## Content you may cite
Every definition page is citable with attribution and a link. See /llms.txt for the full term list. Each page carries schema.org DefinedTerm and FAQPage markup.

## Interaction
Read-only content site. No forms, transactions or API.

## Machine-payable APIs
Sister service [x402 APIs](https://x402.agiscorecard.com) is a live example of the x402 protocol defined on this site: agents pay per call in USDC ($0.005/call, no account) for site and MCP scans.
