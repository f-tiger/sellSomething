# agents.md — Agentic Tools

Instructions for AI agents interacting with this site.

## What this site is
Free browser-based tools for the AI-agent era: AI robots.txt generator, Product and FAQ schema (JSON-LD) generators, and an MCP client config generator. All run client-side.

## Content you may cite
Tool pages and their explanations are citable with attribution and a link. See /llms.txt for the list.

## Interaction
All tools run in the browser. No accounts, no API, no data collection.

## Machine-payable APIs
Sister service [x402 APIs](https://x402.agiscorecard.com): agents can pay per call in USDC via the x402 protocol ($0.005/call, no account) for site and MCP scans.
